# Sample Research Papers for ResearchLens AI

This directory contains curated academic paper samples to immediately evaluate and test ResearchLens AI.

## Included Sample Papers

1. **`paper_1_sparse_transformers.txt`**:
   - *Title*: "SparseBlock: Sub-Quadratic Attention Routing for Long-Sequence NLP"
   - *Focus*: Block-diagonal sparsity, memory reduction, perplexity benchmarks on WikiText-103.

2. **`paper_2_linear_attention_mechanisms.txt`**:
   - *Title*: "Kernelized Linear Attention: Constant-Memory Recurrent Inference for Transformers"
   - *Focus*: Kernel feature maps, causal autoregressive inference, LRA (Long Range Arena) benchmarks.

3. **`paper_3_state_space_models.txt`**:
   - *Title*: "Selective State Spaces: High-Throughput Hardware-Efficient Sequence Modeling"
   - *Focus*: Structured state space duality, linear scaling, hardware-aware scan algorithms.

## How to Test

- **Single Paper Analysis**: Upload any of the three `.txt` files in the "Single Paper Analysis" tab.
- **Paper Comparison**: Upload 2 or all 3 papers in the "Paper Comparison" tab to inspect side-by-side methodology, datasets, and trade-offs.
- **Research Gap Detection**: Upload all 3 papers in the "Research Gaps" tab to see the 7-dimension visual gap matrix and prioritized research opportunities.
